# Overleaf source

`main.tex` is a self-contained operating guide for running a TAG training session.

**To use it:** in Overleaf, *New Project -> Upload Project* and drop in `main.tex`
(or paste it into a blank project). Compile with **pdfLaTeX**. It needs no
external figures, `.bib`, or class files — only packages already present in
Overleaf's TeX Live: `geometry`, `listings`, `booktabs`, `enumitem`, `tikz`,
`xcolor`, `hyperref`, `microtype`, `lmodern`.

Keep it in step with `docs/TRAINING.md` and
`tag_state_estimation/AI_MAP_ESTIMATOR.md`, which cover the same procedures in
Markdown.
